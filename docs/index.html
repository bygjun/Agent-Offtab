작은 창에서 하는 일

대기 중인 작업 확인
입력·승인 대기를 목록 위에 모읍니다. 백그라운드 작업이 끝나면 결과를 읽을 때까지 완료로 남습니다.
원본 채팅 열기
제목과 최근 메시지를 보고 세션을 클릭하면 해당 Codex 또는 Claude Code 채팅이 열립니다.
필요한 세션만 남기기
우클릭해 목록에서 제외할 수 있습니다. 해당 채팅에 새 메시지를 보내면 다시 표시됩니다.

DMG를 열고 Offtab을 응용 프로그램 폴더로 드래그하세요. Apple Silicon Mac용이며 macOS 14 이상을 권장합니다.
